# Umer Baig Portfolio Website

Premium personal portfolio for Umer Baig, SEO, GEO & AEO Specialist. 

## Features
- Custom "Template 05" inspired dark-and-gold aesthetic.
- Fully responsive design using Tailwind CSS v4.
- Performance and metric separation between SEO and Google Ads.
- Interactive case studies and filtered galleries.
- Framer Motion animations for polished interactions.

## Project Structure
- `src/components/layout/`: Global navigation and footer.
- `src/components/sections/`: Primary content sections (Hero, About, Services, Case Studies, etc.).
- `src/components/ui/`: Reusable UI components (Buttons, Headings).
- `src/data/`: Centralized content structure for easy updates without touching UI code.
- `src/index.css`: Tailwind configuration and custom CSS variables.

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run the development server:**
   ```bash
   npm run dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   ```

## Integrations Needed

- **Contact Form:** The form in `Contact.tsx` is currently in demonstration mode. To make it functional, connect it to a form delivery backend like Formspree, Netlify Forms, or your own custom API endpoint.
